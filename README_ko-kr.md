## 사용 방법

1. 게임을 켜고 <kbd>C</kbd> 를 눌러요. 왼쪽 위에 치트 창이 열려요.
2. 창이 안 보이나요? 마우스가 다른 곳에 있으면 창이 흐려져요. 게임의 왼쪽 위로 마우스를 올리면 다시 또렷해져요.
3. 왼쪽 메뉴에서 패널을 고르거나 <kbd>Ctrl</kbd> + <kbd>K</kbd> 를 눌러 찾아요.

## 게임의 nwjs 버전이 0.26.4 보다 낮은 경우 (=옛날 버전의 MV 게임인 경우)

치트는 NW.js 0.26.4 이상에서 돌아요. 그보다 낮으면 게임을 켤 때 경고가 뜨고 치트가 제대로 안 돌 수 있어요.

프로그램을 쓰면 게임의 NW.js 를 쉽게 올릴 수 있어요. 🚧 준비 중

## 수동으로 넣기

직접 넣고 싶다면 페이지나 프로그램 없이도 할 수 있어요.

1. 아래 표에서 게임의 엔진을 확인하고 <a href="https://github.com/paramonos/RPG-Maker-MV-MZ-Cheat-UI-Plugin/releases/latest">릴리스</a> 에서 그 zip 을 받아요.
2. 표의 폴더에 압축을 풀어요. 그 자리에 <code>cheat</code> 폴더와 <code>cheat-version-description.json</code> 이 생겨요.
3. <code>main.js</code> 를 따로 복사해 두고, 아래 줄을 더해요.
4. 게임을 켜고 <kbd>C</kbd> 를 눌러요.

<table>
<tr><th></th><th>MV</th><th>MZ</th></tr>
<tr><th scope="row">이 파일이 있으면</th><td><code>www/js/rpg_core.js</code></td><td><code>js/rmmz_core.js</code></td></tr>
<tr><th scope="row">받을 파일</th><td><code>rpg-mv-cheat-{version}.zip</code></td><td><code>rpg-mz-cheat-{version}.zip</code></td></tr>
<tr><th scope="row">압축을 풀 곳</th><td>게임 폴더 안의 <code>www</code> 폴더</td><td>게임 폴더</td></tr>
<tr><th scope="row">고칠 파일</th><td><code>www/js/main.js</code></td><td><code>js/main.js</code></td></tr>
</table>

MV 는 <code>PluginManager.setup($plugins);</code> 바로 다음에 두 줄을 더해요.

```js
PluginManager.setup($plugins);
PluginManager._path = 'js/plugins/';
PluginManager.loadScript('../../cheat/init/import.js');
```

MZ 는 <code>const scriptUrls = [</code> 바로 다음에 한 줄을 더해요.

```js
const scriptUrls = [
    "cheat/init/import.js",
    "js/libs/pixi.js",
```

- <code>cheat/init/import.js</code> 가 든 줄이 이미 있으면 다시 더하지 마세요.
- 폴더에 <code>main.js</code> 가 없으면 게임이 파일 하나로 묶여 있는 거예요. 먼저 풀어야 해요.
- 되돌리려면 복사해 둔 <code>main.js</code> 를 제자리에 놓고, <code>cheat</code> 폴더와 <code>cheat-version-description.json</code> 을 지워요.
