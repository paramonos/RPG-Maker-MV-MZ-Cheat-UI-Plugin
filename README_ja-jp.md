<h1 align="center">RPGツクール MV/MZ チートUI</h1>

<p align="center">RPGツクール MV・MZ のゲーム内で開けるチートウィンドウです。<br><a href="https://paramonos.github.io/RPG-Maker-MV-MZ-Cheat-UI-Plugin/intro/ja.html">紹介ページ</a></p>

## はじめかた

チートの入れ方は 2 通りあります。合うほうを選んでください。

<table>
<tr>
<td width="50%" valign="top">
<b>ブラウザで入れる</b>
<br>ゲームに手軽に入れたいときに。
<ol>
<li>PC のブラウザーで<a href="https://paramonos.github.io/RPG-Maker-MV-MZ-Cheat-UI-Plugin/">「チートを入れる」ページ</a>を開きます。Chrome か Edge がいちばん簡単です。</li>
<li><code>Game.exe</code> があるフォルダーを選ぶか、ページにドラッグします。ブラウザーがフォルダーの変更を確認してきたら許可します。</li>
<li>「チートを入れる」を押します。</li>
<li>ゲームを起動します。</li>
</ol>
<ul>
<li>Firefox や Safari のようにフォルダーに書き込めないブラウザーでは、このゲーム用の zip をダウンロードします。展開してゲームフォルダーに貼り付けるだけです。</li>
<li>Brave は設定をひとつオンにすれば、Chrome と同じように直接入れられます。やり方はページが案内します。</li>
<li>Program Files の中のゲームはブラウザーが開けません。そのときは「zip で受け取る」で入れてください。</li>
<li>変わるファイルは同じフォルダーに先にバックアップするので、同じページで元に戻せます。チートの設定ファイルは元に戻しても残ります。</li>
<li>ページは韓国語、英語、日本語、中国語で表示できます。</li>
</ul>

<td width="50%" valign="top">

## 使いかた

1. ゲームを起動して <kbd>C</kbd> を押します。左上にチートウィンドウが開きます。
2. ウィンドウが見えませんか。マウスがほかの場所にあるとウィンドウは薄くなります。ゲームの左上にマウスを乗せると、はっきり表示されます。
3. 左のメニューでパネルを選ぶか、<kbd>Ctrl</kbd> + <kbd>K</kbd> を押して探します。

## ゲームの NW.js が 0.26.4 より古い場合

チートは NW.js 0.26.4 以降で動きます。それより古いと、ゲームの起動時に警告が出て、チートが正しく動かないことがあります。主に古い MV のゲームで起こります。

アプリを使えば、ゲームの NW.js を簡単に更新できます。 🚧 準備中

## 手動で入れる

自分で入れたい場合は、ページやアプリを使わなくても入れられます。

1. 下の表でゲームのエンジンを確認し、<a href="https://github.com/paramonos/RPG-Maker-MV-MZ-Cheat-UI-Plugin/releases/latest">リリース</a>からその zip をダウンロードします。
2. 表のフォルダーに展開します。そこに <code>cheat</code> フォルダーと <code>cheat-version-description.json</code> ができます。
3. <code>main.js</code> を別の場所にコピーしてから、下の行を追加します。
4. ゲームを起動して <kbd>C</kbd> を押します。

<table>
<tr><th></th><th>MV</th><th>MZ</th></tr>
<tr><th scope="row">このファイルがあれば</th><td><code>www/js/rpg_core.js</code></td><td><code>js/rmmz_core.js</code></td></tr>
<tr><th scope="row">ダウンロードするファイル</th><td><code>rpg-mv-cheat-{version}.zip</code></td><td><code>rpg-mz-cheat-{version}.zip</code></td></tr>
<tr><th scope="row">展開先</th><td>ゲームフォルダー内の <code>www</code> フォルダー</td><td>ゲームフォルダー</td></tr>
<tr><th scope="row">編集するファイル</th><td><code>www/js/main.js</code></td><td><code>js/main.js</code></td></tr>
</table>

MV は <code>PluginManager.setup($plugins);</code> のすぐ次に 3 行追加します。

```js
PluginManager.setup($plugins);
// auto generated for cheat
PluginManager._path = 'js/plugins/';
PluginManager.loadScript('../../cheat/init/import.js');
```

MZ は <code>const scriptUrls = [</code> のすぐ次に 1 行追加します。

```js
const scriptUrls = [
    "cheat/init/import.js",
    "js/libs/pixi.js",
```

- <code>cheat/init/import.js</code> を含む行がすでにある場合は、追加しないでください。
- フォルダーに <code>main.js</code> がない場合、ゲームが 1 つのファイルにまとめられています。先に展開してください。
- 元に戻すには、コピーしておいた <code>main.js</code> を戻し、<code>cheat</code> フォルダーと <code>cheat-version-description.json</code> を削除します。
