RPG Maker MV · MZ 게임 안에서 바로 여는 치트 창이에요.

게임에서처럼 C 를 누르면 창이 열리고 닫혀요.

시작하기

치트를 넣는 방법은 두 가지예요. 나에게 맞는 쪽을 고르세요.

웹에서 넣기

게임에 간단하게 넣고 싶을 때.

  1. PC 브라우저로 치트 넣기 페이지 를 열어요. Chrome 이나 Edge 가 가장 쉬워요.
  2. Game.exe 가 있는 폴더를 고르거나 페이지로 끌어다 놓아요. 브라우저가 폴더 수정을 물으면 허용해요.
  3. 「치트 넣기」를 눌러요.
  4. 게임을 켜요.
  • Firefox · Safari 처럼 폴더에 쓰지 못하는 브라우저에서는 이 게임에 맞춘 압축 파일을 받아요. 풀어서 게임 폴더에 붙여넣기만 하면 돼요.
  • Brave 는 설정 하나만 켜면 Chrome 처럼 바로 넣을 수 있어요. 켜는 방법은 페이지가 알려 줘요.
  • Program Files 안의 게임은 브라우저가 열어 주지 않아요. 그럴 때도 「압축 파일로 받기」로 넣으면 돼요.
  • 바뀌는 파일은 같은 폴더에 먼저 백업해서, 같은 페이지에서 원래대로 되돌릴 수 있어요. 치트 설정 파일은 되돌려도 남아요.
  • 페이지는 한국어, 영어, 일본어, 중국어로 볼 수 있어요.

프로그램으로 넣기 준비 중

여러 게임의 패치를 관리하고, 치트 설정도 함께 관리하고 싶을 때.

  1. 프로그램을 받아요.
  2. 게임 폴더를 더해요.
  3. 치트를 넣을 게임을 고르고 치트 설정도 함께 적용해요.

이런 걸 할 수 있어요

기능 찾기 Ctrl + K

어디 있는지 몰라도 괜찮아요. 이름 몇 글자만 치면 패널과 설정, 단축키까지 찾아서 그 자리로 데려다줘요.

일반 치트

벽 통과로 어디든 걸어 다니고, 골드와 이동 속도를 원하는 대로 바꿔요. 게임의 타이머를 새로 걸거나 끄고, 고정해서 시간이 줄지 않게 할 수도 있어요.

체력·전투

전투를 바로 이기거나 지거나 도망쳐요. 아군과 적의 HP · MP · TP 를 고치고, 한 번에 회복하거나 0 · 1 로 만들어요. 랜덤 인카운터도 끌 수 있어요.

적 편집 · 소환

적의 능력치와 행동을 고쳐요. 원하는 적 그룹이나 고른 적과 바로 싸우고, 싸우는 중에 적을 더 불러낼 수도 있어요. 고친 값은 게임을 저장하면 남아요.

능력치

캐릭터마다 레벨, 경험치, 능력치를 고쳐요. 직업을 바꾸고, 상태를 걸거나 풀고, 스킬을 배우거나 잊게 할 수 있어요. 무적을 켜거나 파티에 넣고 뺄 수도 있어요.

스킬 · 직업

스킬의 소모, 성공률, 피해 계산식 같은 값을 고쳐요. 직업은 능력치 곡선, 경험치 곡선, 레벨업 스킬, 특성까지 바꿀 수 있어요. 고친 값은 게임을 저장하면 남아요.

아이템 · 장비

아이템, 무기, 방어구를 이름이나 설명으로 찾아서 원하는 개수를 적어요.

자세한 툴팁

아이템, 장비, 스킬, 직업, 상태, 적에 마우스를 올리면 능력치, 특성, 효과, 가격을 카드로 보여 줘요.

값 고정 · 즐겨찾기

아이템 · 장비 개수, 골드, 변수, 스위치, 상태, 타이머를 고정하면 게임이 바꿔도 그대로예요. 자주 쓰는 줄은 별을 달아 맨 위에 모아요. 둘 다 게임마다 따로 남고 설정 백업에는 안 들어가요.

스위치

이름으로 찾아서 하나씩 켜고 끄거나, 목록에 보이는 것을 한 번에 바꿔요.

변수

이름으로 찾아서 값의 종류를 유지한 채 고쳐요. 정수, 실수, 문자열, 참거짓, 배열, 객체, 날짜를 모두 다뤄요. 객체는 펼쳐서 고치거나 JSON 으로 고칠 수 있어요.

값 비교

지금 값을 스냅샷으로 찍어 두고, 게임을 조금 한 뒤 무엇이 바뀌었는지 봐요. 변수, 스위치, 캐릭터, 아이템이 어떻게 바뀌었는지 한눈에 보여서 퀘스트가 쓰는 변수도 쉽게 찾아요. 스냅샷은 파일로 남아요.

맵 이벤트

맵마다 이벤트를 목록으로 보고, 내용을 편집기처럼 읽어요. 셀프 스위치를 바꾸거나 바로 실행하고, 곁으로 가거나 지우고 옮길 수도 있어요.

텔레포트 · 위치 저장 Ctrl + T

맵을 고르고 미니맵에서 칸을 누르면 바로 이동해요. 마음에 드는 자리는 저장해 두고 언제든 돌아와요.

미니맵 창 M

치트 창을 열지 않고 M 으로 지금 맵의 미니맵을 띄워요. 칸을 두 번 누르면 화면 전환 없이 바로 가요. 「이벤트 보이기」를 켜고 이벤트를 누르면 맵 이벤트에서 그 이벤트를 열고, 고른 칸은 제목 줄 단추로 바로 저장해요.

대화 기록 H

놓친 대사가 있나요? 지나간 대사를 다시 읽고 검색해요.

게임 속도 · 메시지 스킵 S

게임 전체의 빠르기를 x0.1 부터 x10 까지 바꿔요. 전투에서만 빠르게 할 수도 있어요. S 를 누르고 있으면 메시지가 쭉 넘어가요.

단축키

창을 열지 않고도 저장, 불러오기, 벽 통과, 전투 승리 같은 치트를 키 하나로 써요. 키는 원하는 대로 바꿀 수 있어요.

게임 옵션

항상 대시, 명령 기억, 소리 크기를 치트 창에서 바꿔요. 여기서 바꾼 것만 설정 백업에 들어가서, 새 게임에 백업을 복원하면 옵션을 다시 맞출 필요가 없어요.

설정 백업

단축키, 번역기, 속도, 게임 옵션 같은 치트 설정을 폴더에 백업하고 다른 게임에서 복원해요. API 키처럼 민감한 값은 넣을지 백업할 때 물어봐요.

번역

쓰는 번역기를 연결해요. ezTrans, LM Studio, Ollama, LibreTranslate, DeepL, 구글 번역, 파파고 예시가 들어 있고, 다른 API 도 주소와 형식만 적으면 돼요. 게임 화면이나 치트 패널의 글을 번역하고, 번역한 글은 저장해 두고 다시 써요.

다국어

치트 창은 한국어, 영어, 일본어, 중국어(간체)로 볼 수 있어요. 설정에서 고르면 바로 바뀌어요.

이 밖에도 빠른 저장 · 불러오기, 왼쪽 메뉴 접기, 네 변을 끌어 창 크기 바꾸기가 있어요. 전부 인터넷 없이 돌아가요.

사용 방법

  1. 게임을 켜고 C 를 눌러요. 왼쪽 위에 치트 창이 열려요.
  2. 창이 안 보이나요? 마우스가 다른 곳에 있으면 창이 흐려져요. 게임의 왼쪽 위로 마우스를 올리면 다시 또렷해져요.
  3. 왼쪽 메뉴에서 패널을 고르거나 Ctrl + K 를 눌러 찾아요.

흐려지지 않게 하려면 제목 줄의 눈 모양 단추를 꺼요.

게임을 켤 때 치트가 새 버전을 확인해서 알아서 바꿔요. 설정 > 업데이트에서 끌 수 있어요.

게임의 nwjs 버전이 0.26.4 보다 낮은 경우 (=옛날 버전의 MV 게임인 경우)

치트는 NW.js 0.26.4 이상에서 돌아요. 그보다 낮으면 게임을 켤 때 경고가 뜨고 치트가 제대로 안 돌 수 있어요.
