最新版本

在 RPG Maker MV、MZ 游戏里直接打开的作弊窗口。

和在游戏里一样，按 C 就能打开和关闭窗口。

开始使用

添加作弊有两种方式，选适合你的那种。

用网页添加

想简单地给游戏加上时。

  1. 在电脑的浏览器里打开“添加作弊”页面。用 Chrome 或 Edge 最简单。
  2. 选择有 Game.exe 的文件夹，也可以直接拖到页面上。如果浏览器询问是否允许修改文件夹，请选择允许。
  3. 点击“添加作弊”。
  4. 启动游戏。
  • 在 Firefox、Safari 等不能写入文件夹的浏览器里，下载按这个游戏做好的压缩包，解压后粘贴到游戏文件夹就行。
  • Brave 只要打开一个设置，就能像 Chrome 一样直接添加。页面会告诉你怎么打开。
  • 浏览器打不开 Program Files 里的游戏。这时用“改用压缩包”来添加。
  • 会改动的文件先备份到同一文件夹，可以在同一页面还原。还原后作弊的设置文件还留着。
  • 页面支持韩语、英语、日语和中文。

用程序添加 准备中

想统一管理多个游戏的补丁和作弊设置时。

  1. 下载程序。
  2. 添加游戏文件夹。
  3. 选择要添加作弊的游戏，并一起应用作弊设置。

能做什么

查找功能 Ctrl + K

不知道功能在哪也没关系。输入名称的几个字，就能找到面板、设置和快捷键，并直接带你过去。

常用作弊

开穿墙到处走，金币和移动速度也能改成你想要的值。还能开始或停止游戏的计时器，或者把它锁定，让时间不再减少。

HP·战斗

战斗可以立刻胜利、失败或逃跑。可以修改我方和敌人的 HP、MP、TP，也能一次全部恢复，或者变成 0、1。还可以关闭随机遇敌。

编辑与召唤敌人

修改敌人的能力值和行动。可以直接和任意敌群或选中的敌人战斗，战斗中还能再叫来敌人。存档后修改会保留。

能力值

逐个角色修改等级、经验值和能力值。还可以更换职业、附加或解除状态、学会或遗忘技能，开无敌，让角色入队或离队。

技能与职业

修改技能的消耗、成功率、伤害公式等数值。职业的能力值曲线、经验值曲线、升级技能和特性也能改。存档后修改会保留。

物品与装备

按名称或说明搜索物品、武器和防具，直接填上想要的数量。

详细提示

把鼠标移到物品、装备、技能、职业、状态或敌人上，就会用卡片显示能力值、特性、效果和价格。

锁定与收藏

锁定物品和装备的数量、金币、变量、开关、状态或计时器后，游戏改了也会保持不变。常用的行加上星标，就会排在最上面。两者都按游戏分别保存，不会进入设置备份。

开关

按名称搜索，可以逐个切换，也可以一次切换列表中的全部。

变量

按名称搜索，修改时保持值的类型不变。支持整数、小数、文本、是/否、数组、对象和日期。对象可以展开修改，也可以用 JSON 修改。

数值对比

先把当前的数值拍成快照，玩一会儿后看看哪些变了。变量、开关、角色和物品的变化一目了然，任务用的变量也很好找。快照会保存成文件。

地图事件

按地图列出事件，像在编辑器里一样查看内容。可以切换独立开关、立即执行、走到旁边，也能消除或移动事件。

传送与地点收藏 Ctrl + T

选好地图，在小地图上点一格就能过去。喜欢的地点可以收藏，随时回来。

小地图窗口 M

不用打开作弊窗口，按 M 就能显示当前地图的小地图。双击格子会直接过去，不切换画面。打开“显示事件”后点击事件，会在地图事件里打开它；选中的格子可以用标题栏的按钮直接保存。

对话记录 H

错过了台词？可以重新看，也能搜索。

游戏速度与跳过对话 S

整个游戏的速度可以在 x0.1 到 x10 之间调整，也可以只在战斗时加速。按住 S，对话就会一路跳过。

快捷键

不用打开窗口，一个键就能存档、读档、穿墙、强制战斗胜利等等。按键可以随意更改。

游戏选项

在作弊窗口里修改始终奔跑、记住指令和音量。只有在这里改过的项目才会进入设置备份，在新游戏里恢复备份后，就不用重新调选项了。

设置备份

把快捷键、翻译器、速度、游戏选项等作弊设置备份到文件夹，再在别的游戏里恢复。API 密钥这类敏感的值，备份时会先问你要不要包含。

翻译

接上你在用的翻译器。内置 ezTrans、LM Studio、Ollama、LibreTranslate、DeepL、Google 翻译和 Papago 的示例，其他 API 填好地址和格式也能用。可以翻译游戏画面或作弊面板里的文字，译文会保存下来重复使用。

多语言

作弊窗口支持韩语、英语、日语和简体中文。在设置里选好后马上切换。

此外还有快速存档、读档，可以折叠的菜单，以及拖动四边调整窗口大小。这些都不需要联网。

使用方法

  1. 启动游戏后按 C，作弊窗口会在左上角打开。
  2. 看不到窗口？鼠标在别处时窗口会变淡。把鼠标移到游戏左上角，窗口就会变清楚。
  3. 在左侧菜单选择面板，或按 Ctrl + K 查找。

不想让窗口变淡，就关掉标题栏的眼睛按钮。

启动游戏时，作弊会检查新版本并自动更新。可以在设置 > 更新里关闭。

游戏的 NW.js 低于 0.26.4 时
