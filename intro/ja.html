RPGツクール MV・MZ のゲーム内で開けるチートウィンドウです。

ゲームと同じように C を押すと、ウィンドウが開閉します。

はじめかた

チートの入れ方は 2 通りあります。合うほうを選んでください。

ブラウザで入れる

ゲームに手軽に入れたいときに。

  1. PC のブラウザーで「チートを入れる」ページを開きます。Chrome か Edge がいちばん簡単です。
  2. Game.exe があるフォルダーを選ぶか、ページにドラッグします。ブラウザーがフォルダーの変更を確認してきたら許可します。
  3. 「チートを入れる」を押します。
  4. ゲームを起動します。
  • Firefox や Safari のようにフォルダーに書き込めないブラウザーでは、このゲーム用の zip をダウンロードします。展開してゲームフォルダーに貼り付けるだけです。
  • Brave は設定をひとつオンにすれば、Chrome と同じように直接入れられます。やり方はページが案内します。
  • Program Files の中のゲームはブラウザーが開けません。そのときは「zip で受け取る」で入れてください。
  • 変わるファイルは同じフォルダーに先にバックアップするので、同じページで元に戻せます。チートの設定ファイルは元に戻しても残ります。
  • ページは韓国語、英語、日本語、中国語で表示できます。

アプリで入れる 準備中

複数のゲームのパッチを管理し、チート設定もまとめて管理したいときに。

  1. アプリをダウンロードします。
  2. ゲームフォルダーを追加します。
  3. チートを入れるゲームを選び、チート設定もまとめて適用します。

できること

機能を探す Ctrl + K

場所を覚えていなくても大丈夫です。名前の一部を入力すれば、パネル、設定、ショートカットまで見つけて、その場所へ案内します。

基本のチート

壁抜けでどこへでも歩けて、ゴールドや移動速度も好きな値に変えられます。ゲームのタイマーを始めたり止めたり、固定して時間が減らないようにもできます。

HP・戦闘

戦闘にすぐ勝ったり、負けたり、逃げたりできます。味方と敵の HP・MP・TP を変えたり、まとめて回復したり 0・1 にしたりできます。ランダムエンカウントも止められます。

敵の編集・呼び出し

敵の能力値と行動を変えられます。好きな敵グループや選んだ敵とすぐに戦えて、戦闘中に敵を呼び足すこともできます。変えた値はセーブすると残ります。

能力値

キャラクターごとにレベル、経験値、能力値を変更できます。職業の変更、ステートの付与・解除、スキルの習得・忘却もできます。無敵やパーティーへの加入・離脱もできます。

スキル・職業

スキルの消費、成功率、ダメージ計算式などの値を変えられます。職業は能力値曲線、経験値曲線、習得スキル、特徴まで変えられます。変えた値はセーブすると残ります。

アイテム・装備

アイテム、武器、防具を名前や説明で検索して、好きな個数を入力できます。

詳しいツールチップ

アイテム、装備、スキル、職業、ステート、敵にマウスを乗せると、能力値、特徴、効果、価格をカードで見せます。

値の固定・お気に入り

アイテムや装備の個数、ゴールド、変数、スイッチ、ステート、タイマーを固定すると、ゲームが変えてもそのままです。よく使う行は星を付けて一番上にまとめられます。どちらもゲームごとに残り、設定のバックアップには入りません。

スイッチ

名前で検索して 1 つずつ切り替えるか、一覧に表示中のものをまとめて切り替えられます。

変数

名前で検索して、値の種類を保ったまま編集できます。整数、小数、文字列、真偽、配列、複合値、日付に対応しています。複合値は開いて編集するほか、JSON でも編集できます。

値の比較

今の値をスナップショットに撮っておき、少し遊んだあと何が変わったかを見られます。変数、スイッチ、キャラクター、アイテムの変化がひと目でわかるので、クエストが使う変数も見つけやすくなります。スナップショットはファイルに残ります。

マップイベント

マップごとにイベントを一覧で見て、中身をエディターのように読めます。セルフスイッチの切り替え、すぐに実行、そばへの移動、消去や移動もできます。

テレポート・登録地点 Ctrl + T

マップを選んでミニマップのマスをクリックすれば、すぐに移動できます。気に入った場所は登録して、いつでも戻れます。

ミニマップウィンドウ M

チートウィンドウを開かずに、M で今のマップのミニマップを出せます。マスをダブルクリックすると画面切り替えなしですぐ移動します。「イベントを表示」をオンにしてイベントをクリックするとマップイベントでそのイベントを開き、選んだマスはタイトルバーのボタンですぐ登録できます。

会話ログ H

見逃したセリフはありませんか。過ぎたセリフを読み返したり検索したりできます。

ゲーム速度・メッセージ送り S

ゲーム全体の速さを x0.1 から x10 まで変えられます。戦闘中だけ速くすることもできます。S を押している間はメッセージがどんどん進みます。

ショートカット

ウィンドウを開かなくても、セーブ、ロード、壁抜け、戦闘勝利などをキー 1 つで使えます。キーは自由に変えられます。

ゲーム設定

常時ダッシュ、コマンド記憶、音量をチートウィンドウから変えられます。ここで変えたものだけが設定のバックアップに入るので、新しいゲームでバックアップを復元すればオプションを合わせ直す必要はありません。

設定のバックアップ

ショートカット、翻訳ツール、速度、ゲーム設定などのチートの設定をフォルダーにバックアップし、ほかのゲームで復元できます。API キーのような大事な値を入れるかどうかは、バックアップのときに確認します。

翻訳

使っている翻訳ツールをつなげます。ezTrans、LM Studio、Ollama、LibreTranslate、DeepL、Google 翻訳、Papago の例が入っていて、ほかの API もアドレスと形式を書けば使えます。ゲーム画面やチートパネルの文字を翻訳し、翻訳結果は保存して使い回します。

多言語

チートウィンドウは韓国語、英語、日本語、中国語（簡体字）で表示できます。設定で選ぶとすぐに切り替わります。

ほかにも、クイックセーブ・ロード、メニューの折りたたみ、四辺をドラッグしてのウィンドウサイズ変更があります。どれもインターネットなしで動きます。

使いかた

  1. ゲームを起動して C を押します。左上にチートウィンドウが開きます。
  2. ウィンドウが見えませんか。マウスがほかの場所にあるとウィンドウは薄くなります。ゲームの左上にマウスを乗せると、はっきり表示されます。
  3. 左のメニューでパネルを選ぶか、Ctrl + K を押して探します。

薄くならないようにするには、タイトルバーの目のボタンをオフにします。

ゲームの起動時に新しいバージョンを確認して、自動で入れ替えます。設定 > アップデートでオフにできます。

ゲームの NW.js が 0.26.4 より古い場合

チートは NW.js 0.26.4 以降で動きます。それより古いと、ゲームの起動時に警告が出て、チートが正しく動かないことがあります。主に古い MV のゲームで起こります。

アプリを使えば、ゲームの NW.js を簡単に更新できます。 準備中

手動で入れる

自分で入れたい場合は、ページやアプリを使わなくても入れられます。

  1. 下の表でゲームのエンジンを確認し、リリースからその zip をダウンロードします。
