## 使用方法

1. 启动游戏后按 <kbd>C</kbd>，作弊窗口会在左上角打开。
2. 看不到窗口？鼠标在别处时窗口会变淡。把鼠标移到游戏左上角，窗口就会变清楚。
3. 在左侧菜单选择面板，或按 <kbd>Ctrl</kbd> + <kbd>K</kbd> 查找。

## 游戏的 NW.js 低于 0.26.4 时

作弊需要 NW.js 0.26.4 或更高版本。版本更低时，启动游戏会弹出警告，作弊可能无法正常运行。这种情况多见于较旧的 MV 游戏。

## 手动添加

想自己动手的话，不用网页和程序也能添加。

1. 在下表确认游戏的引擎，然后从 <a href="https://github.com/paramonos/RPG-Maker-MV-MZ-Cheat-UI-Plugin/releases/latest">Releases</a> 下载对应的 zip。
2. 解压到表中的文件夹，那里会多出 <code>cheat</code> 文件夹和 <code>cheat-version-description.json</code>。
3. 先把 <code>main.js</code> 另存一份，再加上下面的代码。
4. 启动游戏后按 <kbd>C</kbd>。

<table>
<tr><th></th><th>MV</th><th>MZ</th></tr>
<tr><th scope="row">有这个文件</th><td><code>www/js/rpg_core.js</code></td><td><code>js/rmmz_core.js</code></td></tr>
<tr><th scope="row">要下载的文件</th><td><code>rpg-mv-cheat-{version}.zip</code></td><td><code>rpg-mz-cheat-{version}.zip</code></td></tr>
<tr><th scope="row">解压到</th><td>游戏文件夹里的 <code>www</code> 文件夹</td><td>游戏文件夹</td></tr>
<tr><th scope="row">要修改的文件</th><td><code>www/js/main.js</code></td><td><code>js/main.js</code></td></tr>
</table>

MV：在 <code>PluginManager.setup($plugins);</code> 的下一行加上三行。

```js
PluginManager.setup($plugins);
// auto generated for cheat
PluginManager._path = 'js/plugins/';
PluginManager.loadScript('../../cheat/init/import.js');
```

MZ：在 <code>const scriptUrls = [</code> 的下一行加上一行。

```js
const scriptUrls = [
    "cheat/init/import.js",
    "js/libs/pixi.js",
```

- 如果已经有包含 <code>cheat/init/import.js</code> 的一行，就不要重复添加。
- 文件夹里没有 <code>main.js</code> 时，说明游戏被打包成了一个文件，需要先解包。
- 要还原的话，放回备份的 <code>main.js</code>，再删除 <code>cheat</code> 文件夹和 <code>cheat-version-description.json</code>。
