<h1 align="center">RPG Maker MV/MZ Cheat UI</h1>

<p align="center">A cheat window that opens right inside your RPG Maker MV and MZ games.<br><a href="https://paramonos.github.io/RPG-Maker-MV-MZ-Cheat-UI-Plugin/intro/">Intro page</a></p>

## Get started

There are two ways to add the cheat. Pick the one that suits you.

<table>

<b>In your browser</b>

<li>Pick the folder with <code>Game.exe</code> in it, or drag it onto the page. If the browser asks to change the folder, allow it.</li>

## How to use

1. Start the game and press <kbd>C</kbd>. The cheat window opens in the top left.
2. Can’t see it? The window fades while your mouse is elsewhere. Move the mouse over the top left of the game and it comes back.
3. Pick a panel on the left, or press <kbd>Ctrl</kbd> + <kbd>K</kbd> and search.

To stop the fading, turn off the eye button in the title bar.

When the game starts, the cheat checks for a new version and updates itself. You can turn this off in Settings > Updates.

## If your game’s NW.js is older than 0.26.4

The cheat needs NW.js 0.26.4 or newer. On an older version you’ll see a warning when the game starts, and the cheat may not work properly. This mostly happens with older MV games.

The desktop app can update the game’s NW.js for you. 🚧 Coming soon

## Adding the cheat by hand

Prefer to do it yourself? This works without the page or the app.

1. Find your engine in the table below, then download its zip from <a href="https://github.com/paramonos/RPG-Maker-MV-MZ-Cheat-UI-Plugin/releases/latest">Releases</a>.
2. Unzip it into the folder in the table. A <code>cheat</code> folder and <code>cheat-version-description.json</code> appear there.
3. Copy <code>main.js</code> somewhere safe, then add the lines below to it.
4. Start the game and press <kbd>C</kbd>.

<table>
<tr><th></th><th>MV</th><th>MZ</th></tr>
<tr><th scope="row">Has this file</th><td><code>www/js/rpg_core.js</code></td><td><code>js/rmmz_core.js</code></td></tr>
<tr><th scope="row">Download</th><td><code>rpg-mv-cheat-{version}.zip</code></td><td><code>rpg-mz-cheat-{version}.zip</code></td></tr>
<tr><th scope="row">Unzip into</th><td>The <code>www</code> folder in the game folder</td><td>The game folder</td></tr>
<tr><th scope="row">File to edit</th><td><code>www/js/main.js</code></td><td><code>js/main.js</code></td></tr>
</table>

For MV, add three lines right after <code>PluginManager.setup($plugins);</code>.

```js
PluginManager.setup($plugins);
// auto generated for cheat
PluginManager._path = 'js/plugins/';
PluginManager.loadScript('../../cheat/init/import.js');
```

For MZ, add one line right after <code>const scriptUrls = [</code>.

```js
const scriptUrls = [
    "cheat/init/import.js",
    "js/libs/pixi.js",
```

- If a line with <code>cheat/init/import.js</code> is already there, don’t add it again.
- No <code>main.js</code> in the folder? The game is packed into a single file. Unpack it first.
- To undo it, put your copy of <code>main.js</code> back and delete the <code>cheat</code> folder and <code>cheat-version-description.json</code>.
